# Ingredient allergen tags and diet class: the REVIEWED SOURCE (wave 10c).
# build.py reads this file, checks every name exists, and writes ingredient-allergens.csv (one row per ingredient,
# with a reason) and supabase/seed-allergen-tags.sql. A correction is a line here, never a hand edit of the CSV.
#
# LINE FORMAT     [allergen:basis, ...] {diet_class} reason :: name; name; name
#   allergen      gluten wheat dairy egg fish soy peanuts tree-nuts shellfish mollusks sesame
#   basis         I inherent (it IS the thing / is made from it)   T typical (most products)   V varies (some brands / recipes)
#   {diet_class}  plant honey dairy_egg seafood meat. Optional: derived when omitted (see below).
#   Several lines may name the same ingredient; allergens merge (strongest basis wins) and reasons join.
#
# POLICY
#   P1  Named source: tagged when the ingredient is the allergen or made from it, including named oils
#       (peanut oil, sesame oil, walnut oil, soybean oil). Owner decision: peanut oil = peanuts.
#   P2  Typical formulation: processed / compound items are tagged when the common product contains the allergen
#       (oyster sauce has wheat, curry pastes have shrimp paste, chocolate chips have milkfat and soy lecithin).
#       T and V are both tagged: a false "safe" costs more than a false "contains".
#   P3  "May contain" cross-contact is never modelled. Oats are not tagged for gluten (cross-contact is the risk).
#   P4  Generic refined oils (vegetable, canola, corn, cooking spray, shortening) are not tagged.
#   P5  Coconut is NOT a tree nut (FDA 2025). Nutmeg, butternut squash, water chestnut, tiger nut, lupini are not nuts.
#   P6  shellfish = crustaceans (US major allergen). mollusks (clams, oysters, scallops, squid, snails) are separate.
#   P7  wheat implies gluten. Barley, rye and malt carry gluten only.
#
# DIET CLASS (what the ingredient is, not what a recipe is)
#   Derived when omitted: a dairy/egg tag -> dairy_egg; a fish/shellfish/mollusks tag -> seafood; otherwise the
#   ingredient's filter group (meat -> meat, seafood -> seafood, eggs -> dairy_egg) or plant.
#   plant = no animal product; honey = bee product (vegetarian, not vegan); dairy_egg = vegetarian, not vegan;
#   seafood = pescatarian, not vegetarian; meat = flesh, organ, animal fat, gelatin, meat stock.
#   Cheese counts as vegetarian (animal rennet is not modelled; see docs). Wine / beer / sugar fining is not modelled.
