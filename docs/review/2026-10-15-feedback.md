4. Add placeholder sections further down the landing for future features (search a workout plan, track nutrition). Wants my marketing + product opinion on placeholders ("coming soon" sections).

6. Rewrite "Why we built this" with the purpose in #2, blended with the current copy, so it isn't inconsiderate.

"What you actually get": keep "Cook from what you have" and "Filter by what matters"; rename "Read the spec, not a story" → e.g. "Get all the proper measurements"; keep "Honest sources" as USDA for now. 12. Remove "Max spice". For signed-in users drop the separate "My cookware" list in filters — just the "Only what I can make with my cookware" toggle.
18. "My recipes" didn't show (it is gated off by NEXT_PUBLIC_ENABLE_USER_RECIPES). Going forward: add PLACEHOLDERS early for every future section.
19. Redesign login / sign-up (flat, ugly) — a MODAL over the current page like Polymarket.

**Filters**
10. Total time: add RANGE options (look at other recipe sites), not only "< X min".
11. Filter by INGREDIENT categories (produce, vegetables, fruits, meats, …) — the site is about filtering, ingredients must be filterable.
13. Calories → slider. 14. Protein → slider.

**Recipe page (Apple Cake)**
15. Don't abbreviate ("12 srv" → "12 servings").
15.1 Nutrition: show Calories, Protein, Carbs, Fat; a "More nutrition" dropdown with the rest (nutrition-label style).
15.2 Allergen box: keep the red, but make it take less space / place it better.
15.3 BUG: prep notes contain amounts that don't scale ("unsalted butter, 1 full stick + 2 tablespoons" next to a scaled 2 1/2 tsp) — MyPlate free text in prep_note. Strip/convert amount text from prep notes; also odd decimals (0.2 tsp, 0.3 cup) — use kitchen-friendly fractions.

15.6 Signed out: don't show "missing" marks at all.
